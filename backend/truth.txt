1) What is a data structure? Explain its types.
Ans: A data structure is a method of organizing
and storing data in memory so that it can be
accessed and modified efficiently.
Types:
1. Primitive : int, char, float, pointer
2. Non-primitive:
a) Linear : array, linked list, stack, queue
b) Non-linear : tree, graph
Example: Array stores elements in consecutive
memory locations.
int a[5] = {10, 20, 30, 40, 50};
Applications: database management, operating
systems, searching and sorting.
2) Explain stack and its basic operations.
Ans: Stack is a linear data structure that follows
LIFO (Last In First Out).
Operations: push(), pop(), peek(), isEmpty().
Example:
top
30
20
20
10
C program:
#include <stdio.h>
#define MAX 5
int stack[MAX], top=-1;
void push(int x){
if (top==MAX-1) printf("Overflow\n");
else stack[++top]=x;
}
Applications: function calls, expression evaluation,
undo operations, recursion.
3) Explain queue and its operations.
Ans: Queue is a linear data structure that follows
FIFO (First In First Out).
Operations: enqueue(), dequeue(), front, rear.
Example: 10 20 30
10 20 30
Front Rear
Applications: CPU scheduling, printer queues,
buffering, BFS.
4) Explain singly linked list with a C program.
Ans: A singly linked list is a collection of nodes.
Each node contains data and a pointer to next node.
Example:
10 20 30 NULL
C program:
#include <stdio.h>
#include <stdlib.h>
struct node {
int data;
struct node *next;
};
Advantages: dynamic memory allocation,
easy insertion and deletion.
Disadvantage: extra memory for pointers, no random
access.
5) Explain recursion with an example.
Ans: Recursion is a technique in which a function
calls itself to solve a smaller version of the
same problem.
Example: Factorial of a number.
n! = n * (n-1)!
Base condition: 0! = 1
C program:
#include <stdio.h>
int fact(int n){
if (n=0) return 1;
return n*fact(n-1);
}
Output:
fact(5) = 120
6) Explain linear search and binary search.
Ans: Linear search: Checks each element sequentially.
Binary search: divides the array into halves.
Linear search code:
int linearSearch(int a[], int n, int key){
for (int i=0; i<n; i++)
if (a[i]==key) return i;
return -1;
}
Binary search code:
int binarySearch(int a[], int n, int key){
int low=0, high=n-1, mid;
while (low<=high){
mid=(low+high)/2;
if (a[mid]==key) return mid;
else if (a[mid]<key) low=mid+1;
else high=mid-1;
}
return -1;
}
Comparison:
Linear Binary
Sorted req No Yes
Best case O(1) O(1)
Worst case O(n) O(logn)
7) Explain bubble sort with an example.
Ans: Bubble sort compares adjacent elements and
swaps them if they are in wrong order.
Example: 5, 3, 2, 4
Pass 1: 3, 2, 4, 5
Pass 2: 2, 3, 4, 5
Pass 3: 2, 3, 4, 5
C program:
void bubbleSort(int a[], int n){
for (int i=0; i<n-1; i++){
for (int j=0; j<n-i-1; j++){
if (a[j]>a[j+1]){
int t=a[j]; a[j]=a[j+1];
a[j+1]=t;
}
}
}
}
Time complexity:
Best: O(n^2)
Avg: O(n^2)
Worst: O(n^2)

at most two children (left and right).

In : B A C

9) Explain graph traversal using BFS and DFS.
Ans: Graph consists of vertices and edges.
(i) BFS: level by level, uses queue, shortest path.
(ii) DFS: explores one path, uses stack/recursion.
Time: O(V+E)
10) Explain hashing and collision resolution techniques.
Ans: Hashing maps a key to an index using a hash function.
Example: h(k) = k mod 10, h(25) = 5.
Collision occurs when two keys map to same index.
Techniques: 1. Separate chaining 2. Linear probing
3. Quadratic probing 4. Double hashing
Time: Avg O(1), worst O(n)
